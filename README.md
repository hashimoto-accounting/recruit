# 橋本誠公認会計士事務所 採用サイト Ver.4（最終版）

## 更新方法
1. ZIPを解凍します。
2. GitHubで `hashimoto-accounting/recruit` を開きます。
3. `Add file` → `Upload files` を選択します。
4. 解凍した全ファイルをドラッグ＆ドロップします。
5. `Commit changes` を押します。
6. 数十秒〜数分後に公開サイトを更新して確認します。

公開URL:
https://hashimoto-accounting.github.io/recruit/

古い表示が残る場合は、公開ページで Ctrl + F5 を押してください。
